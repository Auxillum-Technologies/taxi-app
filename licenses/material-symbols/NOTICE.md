# Material Symbols icons (bundled subset)

These SVGs are a curated subset of the Material Symbols (Outlined, 24px, default weight) icon set from
https://github.com/google/material-design-icons, copied at commit `10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7`.

Licensed under the Apache License, Version 2.0 (see `LICENSE` in this folder).
File contents are unchanged from the source SVGs. The only change is the file name:
`symbols/web/<name>/materialsymbolsoutlined/<name>_24px.svg` was saved as `<name>.svg`.

Regenerate or extend the set by copying `symbols/web/<name>/materialsymbolsoutlined/<name>_24px.svg`
from that repository.
